# Пример штаба

Образец закрытого репо процесса — «штаба» вокруг агентов `Skills_Claude`. Это **не готовый продукт**, а то, что твой Claude Code читает и подгоняет под тебя: свои проекты, свой язык, свои пределы. Концепт и промпт, с которым его собирать, — [`docs/гайд-штаба.md`](../../docs/гайд-штаба.md).

Снимок с нашего штаба от 13.10.2026, без наших проектов и решений. На чужом аккаунте целиком не проверялся.

## Что внутри

| Путь | Что это | Подставить |
|---|---|---|
| `CLAUDE.md` | правила сессии штаба | `<ВЛАДЕЛЕЦ>`, `<РЕПО-ШТАБА>`, `<ПОЯС>`, свой опыт, репо с личными данными |
| `docs/01…06`, `docs/токены.md` | скелет документов: замысел, архитектура, план, журнал, решения, процесс | заполняется по ходу работы |
| `docs/проекты/` | каталог проектов: карточка на проект, оглавление собирает скрипт | свои карточки вместо `Пример.md` |
| `docs/ретро/промпт.md` | ретро раз в неделю: разбор прогонов, правки агентов | подстановки в начале файла |
| `docs/аналитик/промпт.md` | аналитик раз в неделю: предлагает задачи меткой `предложение` | то же |
| `docs/консультант/промпт.md` | консультант раз в месяц: проекты и процесс целиком | то же, плюс id Routine |
| `scripts/start.sh` | начало облачной сессии: репо штаба на свежем `main`, клоны активных проектов | — (владелец — из `origin`) |
| `scripts/projects.py` | каталог: поиск, связи, даты, проверка | группы и поля — в начале файла |
| `scripts/summary.py` | сводка прогонов агентов за период — сырьё ретро | — |
| `scripts/reminders.py`, `.github/workflows/напоминания.yml` | раз в неделю — задача о ключах, у которых скоро срок | таблица в `docs/токены.md` |
| `channels/telegram/`, `.github/workflows/telegram.yml` | по желанию: бот Telegram → задача в ящике штаба | `REPO` в `wrangler.toml`; настройка — `channels/telegram/README.md` |

Владелец GitHub в скриптах — из входа: `--gh-owner ЛОГИН`, переменная `SHTAB_OWNER` или владелец `origin` репо штаба.

## Проверить после копирования

```
python3 scripts/projects.py --check          # «изъянов нет», код 0
python3 scripts/summary.py --since 2026-10-01 --until 2026-10-07 --repos <проект>
DRY_RUN=1 GITHUB_REPOSITORY=<логин>/<репо штаба> python3 scripts/reminders.py
cd channels/telegram && node --test           # если берёшь бота
```
